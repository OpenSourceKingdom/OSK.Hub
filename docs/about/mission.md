# Mission

The core ethos of OpenSourceKingdom (OSK) is to provide reusable and configurable services, logic, etc. to help make development of software and applications easier. New libraries will be created, for any language, as needs come up for the developer(s) behind the organization that can add any value to others. The goal is to prevent gate keeping of core logic and functions that isn't the primary business logic of developers or organizations and that can provide valuable tools to others in their software development process.

OSK provides the tools, assets, and any other works in the organization space for others without any requirement to pay, sponsor, or attribute anything to the organization. It would be appreciated, but not required, if attribution to the organization was provided where possible (credits or similar); the primary reason for OSK is to provide benefit to others and is not to gain any viral attention for anything other than to allow access to more developers to the libraries. To this end, OSK provides a simple promise to all who uses the software: none of the tools, libraries, frameworks, applications, etc. that are offered will ever require any form of payment, charge, subscription, or anything similar to use. Sponsorships, donations, or similar are appreciated, but will not be requested.

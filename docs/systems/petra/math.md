## Summary

The math APIs provide an enhancement to standard System Math so that certain aspects of higher level math operations can be more easily configured within a game editor UI. This includes concepts such as math formulas which can be used to perform math function operations like Polynomial, Stepwise, and similar calculations in an easily shared and configurable manner for applications.

### Godot

A Godot integration exists to allow setting formulas as resources with the inspector

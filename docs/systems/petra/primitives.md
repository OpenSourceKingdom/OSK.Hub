## Summary

Primitives is not currently an agnostic library, but an engine specific integration for the Petra framework. This is meant to mainly aid in configuration or similar needs when .NET standard data structures can not be inherently utilized in various game editors.

### Godot Integration

The Godot integraion provides a way to create Timespans, automatic Guid identifiers, and various nullable style data types.

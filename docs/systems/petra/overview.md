# Petra

## Overview

Petra, the 'rock', hearkening to Peter whom God built the church, is meant to serve as a foundation for game development. It provides support for C# style engines for a vast amount of logic in a modular, flexible manner. 

Each library is meant to operate as independently as it can from others in order to allow develoeprs to determine what they will and will not use from the framework and SDKs. The goal of OSK is to provide meaningful shared logic and reusable libraries where users desire it most; however, the Petra framework aims to be a complete game framework that covers most traditional game functions in a configurable manner, in order to help alleviate development of games in most use cases.

If a use case does not easily work in any of the official packages, please reach out and discuss what may be missing in current or nonexistent libraries and it may be considered viable as a new library in the OSK space.

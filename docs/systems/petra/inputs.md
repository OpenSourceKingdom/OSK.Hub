## Summary

An input system is responsible for a wide variety of requirements, ranging from input signaling and receiving to interpreting input state and responding to it, there is a vast amount of logic that can be required to fully configure and implement a good input system.

Petra's input framework aims to reduce the complexity of most of the challenging parts and to provide an API and SDK that requires only configuration to get setup and running.

The inputs libraries attempt to be flexible while providing as much rich information as possible when interacting and responding to user input, across a wide range of devices.

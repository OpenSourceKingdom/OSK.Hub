## Summary

UML diagrams are meant to provide a standard visual guide to designing, analyzing, and devleoping software. These can be geneerated using various tools like [draw.io](https://drawio-app.com/uml-diagrams/) or others, but this library aims to allow integrating UML generation dynamically during or after build processes in CI/CD so that UML diagrams can be generated on a codebase directly rather than needing to be manually handcrafted.
